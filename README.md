# Kwanza Smart

Landing page de venda para a planilha de controlo financeiro Kwanza Smart.

## Conteúdo

- Hero com proposta de valor e pré-visualização do painel financeiro
- Secção explicando o método em três passos
- Benefícios do produto
- Bloco de oferta com CTA de contacto
- FAQ responsivo

## Executar localmente

Como a página é estática, pode ser aberta diretamente no navegador ou servida com:

```bash
python3 -m http.server 4173
```

A página fica disponível em `http://localhost:4173`.

> O endereço de e-mail no CTA é um placeholder editável em `index.html`. Substitua-o pelo canal real de vendas antes de publicar.
